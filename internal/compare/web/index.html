OpenCode vs Command Code

Canonical, schema-v3-aligned comparison. Generation speed and spend use generatedTokens (visible output plus reasoning); input uses inputTotal (fresh + cache read + cache write). Model families and output-size strata keep the comparison honest when the tools run different models.

05

Model families

Short model ids are normalized to a family key (provider prefix, case and separator style removed). Shared families appear in both tools; one-sided families explain where the workload differs.

06

Output-size strata

Generation speed is bucketed by generated tokens. A bucket with fewer than five timed steps on either side is marked low-sample and should be read as indicative only.

08

Sessions and runtime overhead

Session spans and output per minute are derived from windowed steps. Command Code records no per-step wall clock, so active/idle minutes and overhead share are available only for OpenCode and are marked unavailable rather than guessed.
